# 按本轮证据验收

报告使用四种状态：`passed`、`failed`、`not_tested`、`not_applicable`。历史报告、端口监听、预检成功和厂商文档都不能直接填 `passed`。记录本轮应用/组件版本、时间、实际测试进程及证据范围，不复制凭据或完整启动参数。

| 项目 | 通过需要的证据 | 常见误判 |
| --- | --- | --- |
| 桌面登录清理 | 所有实际已选根 Cookie=0、所选存储为空、已知 OAuth 配置字段为空；MCP/正常配置保留；退出后复查未重建 | 只检查旧目录或只删 Cookie |
| 新版兼容 | 当前包、EXE、签名/摘要与真实规则条件一致；安全入口实际启动 | 改 marker 或照抄 36 条等历史数量 |
| 实际出口 | 从专用链路取得本轮允许 IP，当前应用连接也限定在对应网关 | 共享 Clash 测速/普通浏览器检测成功 |
| 失败关闭 | 自有临时锁或排除出口时拒绝新转发并撤销已有转发；无直连回退 | 只测试一次探测失败，未查存量连接 |
| 普通网络 | 保护锁定期间，无关站点仍遵循原路由 | 用普通站点恢复证明 Claude 也恢复 |
| 恢复与稳定性 | 解除自有锁后重新验证才恢复；冷启动、刷新、新窗口及入口切换分别测试；记录耗时 | 要求解除锁瞬间立即成功；把反复关窗口当修复 |
| WebRTC 页面 | 当前页面及新 WebContents 的 ICE/SDP/stats 无未经允许的原始私网/公网候选，刷新后复查 | 命令行包含开关、只查一个显示标签 |
| UDP / IPv6 | 精确目标身份的实际拒绝，配普通进程正对照；UDP 静默需相应内核事件及 socket 归属佐证 | 超时或没收到包就算阻断成功 |
| DNS | 对应环境实际解析路径及失败路径已检查；受保护域名/其他应用分开 | 全部标美国就认定所有 DNS 不泄露 |
| 时区 / 语言 | 实际页面、worker/iframe、所需原生组件分开报告；运行环境重启后复查 | 一个页面 New_York 就断言全部组件已一致 |
| 检测器退出 | 结束自己的测试控制器后按设计暂停受保护联网，重开恢复；原用户锁不变 | 关闭检测器后仍沿用旧 JSON 放行 |
| 登录后功能 | 用户自行登录后，在明确授权范围内实际测试对应功能 | 欢迎页联网就宣称 Cowork/外部 MCP 已验收 |

复查期间不得删除原有网络限制、绕过证书错误、关闭防火墙、强杀有未保存工作的程序或自动登录。管理员只读采集遇到 UAC 必须由用户确认；采集失败应标 `not_tested`，不能改成通过。

出口探测是离散观测，不能保证上游公网 IP 更换瞬间零字节传输。美国出口也不能证明独享、无滥用历史或平台内部信誉；这些不属于本机测试可证明的结论。

## 日常使用说明模板

按实际部署填写，不照抄作者参数：先连接代理并确认住宅出口，再从本机已验收的桌面/网页安全入口打开；等待验证完成后自行登录。入口切换可能触发暂停，恢复依赖重新校验。不要改用普通入口绕过提示。保留当前实现需要的监控窗口；是否支持后台、最小化、睡眠/唤醒要分别说明。新版本提示规则不匹配时先维护验收。清理登录按需做，无须每次使用都清理。

交接最后列出：**本次处理了什么、实际通过什么、尚未验证什么、保留什么，以及遇错如何恢复**。不使用“原生美国环境”“全零泄露”“永不封号”作为验收结论。
