# Claude 运行环境面板

把现有优化后的 Claude 安全环境做成**每秒自动更新的 Windows 桌面面板**。分别查看 Claude 桌面与专用网页的出口、放行/阻断、入口跟随、DNS 定向、时区、语言和 WebRTC 策略。

它读取已有保护与监控，**不是另一套保护，也不是通用手动风险扫描器**。面板不发额外公网请求、不执行 STUN、不操作 DevTools、不更改代理或防火墙、不清理登录。关闭面板不会停止原有保护。

## 前提

- Windows x64，Python 3.10+，包含 Tkinter 与 `pythonw.exe`。
- 已在本机实际部署并验收本仓库兼容的 [保护后端](../backend/README.md)。下载仓库或安装 Skill 本身不算部署完成。
- 原部署有真实的 `installed.json`、`policy.json`、运行时配置、网关、入口跟随器和进程绑定监控。不要复制别人的登记、报告或私密配置来制造通过状态。
- 本面板适配当前源码中的协议与固定端口拓扑。它不是任意 Clash/Claude 安装的自动适配器。

## 打开面板

在仓库根目录运行：

```powershell
pythonw -B detector/app.py
```

默认读取 `%USERPROFILE%\.claude-network-guard`。保护位于其他目录时，使用实际目录，例如：

```powershell
# 示例路径须替换为你自己的已部署保护目录。
pythonw -B detector/app.py --root 'D:\ClaudeGuard'
```

从**原来已验收的安全入口**启动 Claude 桌面或专用网页，面板会自动识别。应用未启动时显示“未运行”；有进程但缺少有效安全登记时显示异常，不使用旧报告补齐。面板不会替你启动服务、登录或切换节点。

### 创建桌面快捷方式

保持仓库在一个稳定位置，再运行：

```powershell
python -B -X utf8 detector/install_shortcut.py
# 使用自定义的已部署保护目录：
python -B -X utf8 detector/install_shortcut.py --guard-root 'D:\ClaudeGuard'
```

创建【Claude 运行环境面板】，指向当前仓库代码、当前 Python 的 `pythonw.exe` 和所选保护目录。移动仓库后需重新创建快捷方式。脚本拒绝覆盖同名快捷方式；可先手动检查、重命名旧快捷方式。`--desktop` 可选择其他现有目录；`--dry-run` 仅验证路径，不创建快捷方式。脚本不复制账号数据、不部署或重启保护。

## 怎样读取界面

- **Claude 桌面 / 专用网页 / 全部监控**：前两类同时显示共享链路信息和对应应用状态。
- **刷新状态 / F5**：请求重新核对后台服务身份；平时每秒自动更新，不必手动刷新。
- **点击一行**：查看证据来源、测量时间、范围与诊断原因。
- **隐藏界面 IP / 导出隐藏 IP**：分别控制显示与导出；导出默认隐藏 IP。报告仅保存在你选的位置，不上传。

| 状态 | 含义 |
| --- | --- |
| 通过 | 该项当前证据有效，请看其具体范围；策略状态不自动升级为泄露实测 |
| 异常 | 如未登记进程、入口不匹配或保护锁定；锁定意味着正在拒绝该链路，不表示已经泄露 |
| 待验证 | 证据过期、读取失败、权限不足或监控未就绪；不计为通过 |
| 未运行 | 已确认对应服务/受保护实例未运行；查询失败不会伪装成已退出 |

## 数据和刷新方式

| 项目 | 数据来源 / 范围 |
| --- | --- |
| 当前家宽出口、联网许可 | 原网关现有双来源出口验证、当前许可和阻断原因，不另外查询 IP |
| 链式代理入口 | 当前跟随器的进程身份、新鲜报告和住宅配置匹配结论，不显示代理密码 |
| DNS 防泄露路由 | 本机专用 DNS 服务身份 + Windows 有效 NRPT 域名定向，是路由配置证据 |
| 桌面时区、语言 | 既有页面监控的有效证明，绑定进程创建时间、nonce、监控器及四秒时效 |
| 桌面 WebRTC | 当前原生 Electron WebContents 策略与监听器证明，不重新采集 ICE |
| 网页时区、语言、WebRTC | 现有进程策略、启动实测和实时监控；不每秒重新运行页面 JavaScript |
| IPv6 / UDP | 展示既有保护范围与可读证据；WFP 权限不足时明确注明未核验 |

面板约每秒读取一次状态，服务完整身份约每 12 秒复核，NRPT/WFP 只读查询约每 25 秒执行。慢查询在独立后台线程中，每类最多一个；目标进程身份与证据新鲜度仍持续核对。刷新面板不能延长许可或把旧证据变新。

## 不代表什么

- 不等于重新完成权威 DNS 泄露、ICE 私网/公网候选、目标进程 UDP/IPv6 流量实测。
- 不提供 Anthropic 官方信任分，不证明住宅 IP 独享、无滥用历史或账号不会受限。
- 不把桌面页面结论扩展为所有原生组件、独立 MCP、普通浏览器或云端 Cowork 的结论。
- 不安装、修复、停用或绕过原保护。没有兼容后端时应先完成部署，不能手写“通过”登记。

测试只证明程序行为；本机观察到服务在线或保护锁定，不等于已经完成运行中 Claude 的全链路验收。

## 开发与离线验证

```powershell
python -B -X utf8 -m unittest discover -s detector -p "test_*.py" -v
python -B -X utf8 detector/app.py --help
python -B -X utf8 detector/install_shortcut.py --help
```

测试使用模拟进程、临时文件和 RFC 文档示例地址，不调用真实公网、不打开 Claude、不改网络规则。Windows CI 在 Python 3.10 / 3.12 上执行这些测试。

读取一次本机现有状态并输出隐藏 IP 的 JSON（不打开 GUI、不额外发公网请求）：

```powershell
python -B -X utf8 detector/app.py --scan
```

源码：`app.py` 为 Tkinter 界面，`monitor.py` 为只读实时观察器，`checks.py` 为证据/报告辅助及早期独立检测实现；面板只调用实时观察器，不调用早期主动探测路径。`install_shortcut.py` 仅创建快捷方式。本目录不附本机运行报告、截图、浏览器资料或 `.lnk` 文件。
